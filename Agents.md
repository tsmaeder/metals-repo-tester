# Agents

This is a simple Node.js command-line application. It tests whether the metals 
language server finds errors in workspace from a list of github repos.

## Goal

- Keep changes small and easy to review.
- Prefer clear, readable code over clever code.

## Common Commands

- Install: `npm install`
- Run (dev): `npm run dev`
- Build: `npm run build`
- Test: `npm test`

## Coding Notes

- Do not guess, ask back
- use "undefined", not "null"
- Use TypeScript for source files.
- Add or update tests when behavior changes.
- Avoid breaking existing CLI flags or output without a clear reason.
- Update docs when commands or arguments change.
- Uses https://microsoft.github.io/language-server-protocol/specifications/lsp/3.17/specification
